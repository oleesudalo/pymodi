01 라이브러리 소개

PyMODI+ 라이브러리란?

Python으로 MODI Plus 모듈을 제어하는 공식 라이브러리입니다.

라이브러리 개요

  • 공식 저장소: github.com/LUXROBO/pymodi-plus
  • 지원 버전: Python 3.7 이상 (권장: Python 3.8)
  • 지원 OS: Windows / macOS / Linux
  • 연결 방식:
    • Serial (USB 유선) - 기본값
    • BLE (블루투스) - 무선

유용한 명령어

  • python -m modi_plus --tutorial
    대화형 튜토리얼 실행
  • python -m modi_plus --inspect
    연결된 모듈 상태 진단
  • python -m modi_plus --usage
    사용 예제 대화형 실행

설치 방법 (Terminal)

# pip로 설치
pip install pymodi-plus

# 최신 버전으로 업그레이드
pip install pymodi-plus --upgrade

# 설치 확인
python -m modi_plus --help

주의사항

호환성 및 안정적인 구동을 위해 반드시 Python 3.8.10 버전으로 설치해 주세요!

01 라이브러리 소개

기본 사용법 – MODIPlus 객체 생성

bundle을 만들고 모듈에 접근하는 공통 패턴입니다.

꼭 기억하세요

  • Network 모듈이 USB에 연결되어 있어야 합니다.
  • n번째 모듈 접근은 [n-1]을 사용합니다.
  • 하드웨어 제어 시 time.sleep()으로 딜레이를 줍니다.
  • 값 읽기 전 최소 1초 대기를 권장합니다.

main.py

# 1) 라이브러리 불러오기
import modi_plus
import time

# 2) MODIPlus 객체 생성 (= bundle)
#    Network 모듈을 USB로 연결한 상태여야 함
bundle = modi_plus.MODIPlus()

# 3) 연결된 모듈 확인
print(bundle.modules)

# 4) 모듈별 리스트 접근
print(bundle.leds)        # LED 모듈 리스트
print(bundle.dials)       # Dial 모듈 리스트
print(bundle.speakers)    # Speaker 모듈 리스트

# 5) 첫 번째 모듈 변수에 저장 (n번째는 [n-1])
led  = bundle.leds[0]
dial = bundle.dials[0]

# 6) 모듈 제어 및 값 읽기
led.rgb = (255, 0, 0)     # 빨간색 LED
print(dial.turn)          # 다이얼 각도 출력

connection.py (연결 방식)

# 1) USB 시리얼 (기본값)
bundle = modi_plus.MODIPlus(connection_type="serialport")

# 2) BLE 블루투스 (무선)
bundle = modi_plus.MODIPlus(conn_type="ble", network_uuid="XXXXXXXX")

💡 연결 안 될 때?

  1. USB 케이블 다시 꽂기
  2. Network 모듈 펌웨어 확인
  3. 터미널에서 python -m modi_plus --inspect 실행

하드웨어 사용법

MODI+ 모듈의 물리적인 특징과 관리 방법입니다.

모듈 종류 (색상별)

  • 노랑: 네트워크, 배터리 모듈
  • 초록: 입력 모듈 (센서 등)
  • 빨강: 출력 모듈 (모터, LED 등)

배터리 상태 체크

  • 초록불: 완충
  • 노랑불: 70% 이상 (약 1시간 정도 사용 가능)
  • 빨강불: 배터리 부족
가급적 배터리 없이 USB 데이터 케이블을 직접 연결하여 사용하는 것을 추천합니다.

하드웨어 초기화

만약 모듈이 오작동하여 펌웨어 초기화가 필요한 경우, 공식 웹 에디터를 사용하세요.

모디코드에디터(MODI Planet) 접속하여 초기화하기
02 입력 모듈

Button 모듈

버튼클릭 · 더블클릭 · 토글 · 누른 상태 4가지 모드를 감지합니다.

속성 / 메서드 설명 범위 / 반환
button.clicked 한 번 클릭되었는지 True / False
button.double_clicked 더블클릭되었는지 True / False
button.pressed 현재 눌려있는지 True / False
button.toggled 토글 (눌릴때마다 전환) True / False

button_example.py

import modi_plus
import time

bundle = modi_plus.MODIPlus()
button = bundle.buttons[0]

# 버튼 상태 무한 확인
while True:
    if button.clicked:
        print("한 번 클릭!")
    if button.double_clicked:
        print("더블클릭!")
    if button.pressed:
        print("누르고 있음")
    if button.toggled:
        print("토글 상태 전환")
        
    time.sleep(0.1)    # 반드시 딜레이!
02 입력 모듈

Dial 모듈

다이얼 손잡이 회전 각도와 속도를 측정합니다.

속성 / 메서드 설명 범위 / 반환
dial.turn 현재 다이얼 각도 0 ~ 100
dial.speed 다이얼 회전 속도 -100 ~ 100

💡 활용 팁

  • dial.turn 값을 LED 밝기, 모터 속도에 직접 연결해 아날로그 조절기로 활용
  • dial.speed는 양수=시계방향 / 음수=반시계방향
  • 값은 10 단위로 변경됩니다.

dial_example.py

import modi_plus
import time

bundle = modi_plus.MODIPlus()
dial   = bundle.dials[0]
led    = bundle.leds[0]

# 다이얼 현재 값 출력
print("각도 :", dial.turn)
print("속도 :", dial.speed)

# 다이얼로 LED 밝기 조절 (응용)
while True:
    value = dial.turn
    # 0~100을 0~255로 변환
    brightness = int(value * 2.55)
    
    led.rgb = (brightness, brightness, brightness)
    time.sleep(0.1)
02 입력 모듈

Env 모듈 (환경센서)

온도 · 습도 · 조도 · 주변 소리 등 주변 환경을 측정합니다.

속성 / 메서드 설명 범위 / 반환
env.temperature 온도 (℃) -40 ~ 85
env.humidity 습도 (%) 0 ~ 100
env.illuminance 조도 (밝기) 0 ~ 100
env.volume 주변 소리 크기 0 ~ 100

env_example.py

import modi_plus
import time

bundle = modi_plus.MODIPlus()
env    = bundle.envs[0]

# 초기화 대기 (첫 값은 0)
time.sleep(1)

# 환경 값 출력
print(f"온도: {env.temperature} ℃")
print(f"습도: {env.humidity} %")
print(f"밝기: {env.illuminance}")
print(f"소리: {env.volume}")

# 예: 어두워지면 알림
while True:
    if env.illuminance < 20:
        print("너무 어두워요!")
    time.sleep(1)
02 입력 모듈

IMU 모듈 (자이로·가속도)

3축 가속도 · 각속도 · 회전 각도를 측정하는 관성 센서입니다.

속성 / 메서드 설명 범위 / 반환
imu.acceleration_x/y/z X/Y/Z축 가속도 (m/s²) -39 ~ 39
imu.angular_vel_x/y/z X/Y/Z축 각속도 (도/초) -500 ~ 500
imu.vibration 흔들림 0 ~ 100
imu.angle Roll, pitch, yaw 순서 반환 -180 ~ 180

imu_example.py

import modi_plus
import time

bundle = modi_plus.MODIPlus()
imu    = bundle.imus[0]

time.sleep(1)   # 초기화 대기

# 기울기 각도
print(f"Angle  : {imu.angle}")

# 흔들림(가속도) 감지
while True:
    z = imu.vibration
    if abs(z) > 20:
        print("흔들림 감지!")
    else:
        print("흔들림 없음")
    time.sleep(0.1)
02 입력 모듈

ToF 모듈 (거리센서)

레이저(적외선)로 물체까지의 거리를 측정합니다.

속성 / 메서드 설명 범위 / 반환
tof.distance 물체까지 거리 (cm) 0 ~ 100

💡 ToF 원리

적외선을 쏘고 반사되어 돌아올 때까지 걸린 시간(Time of Flight)으로 거리를 계산합니다.

⚠ 주의사항

  • 거리는 0~100 cm 범위만 측정
  • 투명/반사가 심한 표면에서는 부정확
  • 태양광 강한 곳에서는 오차 증가

tof_example.py

import modi_plus
import time

bundle = modi_plus.MODIPlus()
tof    = bundle.tofs[0]

time.sleep(1)

# 현재 거리 읽기
distance = tof.distance
print(f"거리: {distance} cm")

# 가까워지면 경고
while True:
    d = tof.distance
    if d < 10:
        print("너무 가까워요!")
    elif d < 30:
        print("주의하세요")
    else:
        print("안전 거리")
    time.sleep(0.3)
02 입력 모듈

Joystick 모듈

X·Y축 위치와 방향을 감지하는 입력 모듈입니다.

속성 / 메서드 설명 범위 / 반환
joystick.x X축 위치 -100 ~ 100
joystick.y Y축 위치 -100 ~ 100
joystick.direction 방향 문자열 'up', 'down', 'left', 'right', 'origin'

📌 direction 반환값

'up' : 위로 밀었을 때
'down' : 아래로 밀었을 때
'left' : 왼쪽으로 밀었을 때
'right' : 오른쪽으로 밀었을 때
'origin' : 중립 (가운데)

joystick_example.py

import modi_plus
import time

bundle   = modi_plus.MODIPlus()
joystick = bundle.joysticks[0]
led      = bundle.leds[0]

# X·Y 좌표값 출력
print(joystick.x)
print(joystick.y)

# 방향으로 LED 색상 제어
while True:
    d = joystick.direction
    if d == "up":
        led.rgb = (0, 255, 0)    # 초록
    elif d == "down":
        led.rgb = (0, 0, 255)    # 파랑
    elif d == "left":
        led.rgb = (255, 165, 0)  # 주황
    elif d == "right":
        led.rgb = (255, 0, 0)    # 빨강
    else:
        led.turn_off()
        
    time.sleep(0.1)
03 출력 모듈

LED 모듈

RGB 색상 조합으로 다양한 빛을 표현합니다. (각 채널 0~255)

속성 / 메서드 설명 범위 / 반환
led.red R값 (빨강) 0 ~ 100
led.green G값 (초록) 0 ~ 100
led.blue B값 (파랑) 0 ~ 100
led.rgb = (R, G, B) 한 번에 설정 (권장) (0~255) × 3
led.turn_on() 흰색 최대 밝기 method
led.turn_off() LED 끄기 method

led_example.py

import modi_plus
import time

bundle = modi_plus.MODIPlus()
led    = bundle.leds[0]

# 방법 1: 각 색상 개별 설정
led.red   = 100
led.green = 0
led.blue  = 0
time.sleep(1)

# 방법 2: 한 번에 설정 (권장)
led.rgb = (0, 255, 0)      # 초록
time.sleep(1)

led.rgb = (0, 0, 255)      # 파랑
time.sleep(1)

# 끄기
led.turn_off()
03 출력 모듈

Display 모듈

96×96 OLED 화면에 글자·변수·도형을 표시합니다.

속성 / 메서드 설명 범위 / 반환
display.text = "..." 텍스트 설정·표시 str
display.write_text("...") 글자 쓰기 method
display.write_variable_xy(x,y,값) 좌표에 변수 표시
(값은 int타입만 가능)		 method
display.reset() 화면 초기화(지우기) method

💡 텍스트 표시 팁

문자열(text)을 출력할 때는 행 선택이 불가능합니다. 줄바꿈을 원하실 경우, 띄어쓰기(공백)를 여러 개 넣어 강제 줄바꿈을 하는 방식을 사용해야 합니다.

display_example.py

import modi_plus
import time

bundle  = modi_plus.MODIPlus()
display = bundle.displays[0]

# 텍스트 출력
display.text = "Hello MODI"
time.sleep(2)

# 화면 지우기
display.reset()
time.sleep(1)

# 변수 값 특정 위치에 표시
temp = 25
display.write_variable_xy(0, 0, temp)
time.sleep(2)
03 출력 모듈

Speaker 모듈

주파수·볼륨·음계로 소리를 출력합니다. (도·레·미...)

속성 / 메서드 설명 범위 / 반환
speaker.tune = 주파수, 볼륨 주파수+볼륨 동시 설정 (Hz, 0~100)
speaker.frequency 주파수만 설정 20 ~ 8000 Hz
speaker.volume 볼륨만 설정 (주파수 선행 필요) 0 ~ 100
speaker.reset() 초기 상태로 (끄기) method

💡 사용 팁

주파수(frequency) 값은 1000 이상 입력해야 사람의 귀에 소리가 잘 들립니다.

speaker_example.py

import modi_plus
import time

bundle  = modi_plus.MODIPlus()
speaker = bundle.speakers[0]

# 방법 1: tune (가장 많이 사용 ⭐)
speaker.tune = 440, 50    # 라(A4), 볼륨50
time.sleep(1)

# 방법 2: 주파수만
speaker.frequency = 523   # 도(C5)
time.sleep(1)

# 방법 3: 볼륨만 (주파수 먼저 설정 필요!)
speaker.volume = 80
time.sleep(1)

# 끄기
speaker.reset()
03 출력 모듈

Motor 모듈

각도·속도·힘으로 회전 운동을 제어합니다. (컨트롤러+모터 일체형)

속성 / 메서드 설명 범위 / 반환
motor.angle = 각도, 속도 목표 각도로 회전 (0~360, 속도)
motor.speed 연속 회전 속도 (음수=역방향) -100 ~ 100
motor.torque 회전 힘 0 ~ 100
motor.stop() 모터 정지 method

모터 하드웨어 사용 팁

  • 0도 기준점: 모터 축에 있는 검정색 줄과 모터 표면의 A/B 글씨가 만나는 상태가 0도인 상태입니다. (angle 제어 시 참고)
  • 모터 고유 ID 확인: 모터가 여러 개일 경우 print(bundle.modules)로 찍어보고 각 모터의 고유 아이디를 찾아내야 합니다.
  • 모터의 ID는 매번 바뀌는 것이 아니라 하드웨어 고유 아이디를 가지므로, 미리 찾아내서 모터 겉면에 견출지 등으로 써서 붙여놓으면 코딩하기 훨씬 수월합니다!

motor_example.py

import modi_plus
import time

bundle = modi_plus.MODIPlus()
motor  = bundle.motors[0]

# 방법 1: 특정 각도까지 회전
motor.angle = 90, 50    # 90도, 속도50
time.sleep(2)

# 방법 2: 연속 회전 (속도 제어)
motor.speed = 50        # 정방향
time.sleep(2)

motor.speed = -50       # 역방향
time.sleep(2)

# 정지
motor.speed = 0
# 또는 motor.stop()

자주 쓰는 입출력 조합

입력 센서값으로 출력 모듈을 제어하는 전형적인 패턴입니다.

+ 예시 1: 다이얼 + LED 

# 다이얼로 LED 색상 조절
while True:
    value = dial.turn    # 0 ~ 100
    rgb_val = int(value * 2.55)
    
    led.rgb = (rgb_val, 0, 0)
    time.sleep(0.1)

+ 예시 2: ToF + Speaker 

# 가까워지면 경고음
while True:
    if tof.distance < 10:
        speaker.tune = 880, 80
    else:
        speaker.reset()
    time.sleep(0.2)

+ 예시 3: Env + Display 

# 온도를 화면에 표시
while True:
    temp = env.temperature
    display.write_variable_xy(0, 0, temp)
    time.sleep(1)

+ 예시 4: Button + Motor 

# 버튼으로 모터 on/off 토글
running = False
while True:
    if button.clicked:
        running = not running
        motor.speed = 50 if running else 0
    time.sleep(0.1)
